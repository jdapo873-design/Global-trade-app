# 🌐 Global Trade Hub · 全球跨境贸易中控台

跨境卖家一体化工具：利润测算、选品库、3D 全球物流地图、22 国语言、AI 多国文案、PDF 报价单关键信息提取。

## 功能
- 📦 **利润与预测** — 实时利润率、汇率换算
- 📊 **选品库** — CSV 本地持久化
- 🌍 **全球战情室** — pydeck 3D 飞线物流雷达
- 💼 **多国文案** — AI 生成多语言 Listing
- 📄 **PDF 提取** — 上传供应商报价单，AI 自动提取产品名称/单价/起订量/总价
